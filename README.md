# deposit-switch

**예금갈아탈까**는 기존 예금을 만기까지 유지할 때와 중도해지 후 새
예금으로 갈아탈 때의 예상 세후 이자를 비교하는 계산기입니다.

- 서비스 주소: [deposit.pokugi.com](https://deposit.pokugi.com)

## 주요 기능

- 기존 예금 유지와 새 예금 갈아타기의 예상 수익 비교
- 중도해지 금리, 이자 과세율, 갈아타기 비용 반영
- 세전 이자, 예상 세금, 세후 이자 상세 표시
- 가입일, 새 예금 가입 예정일, 만기일 유효성 검사
- URL을 통한 계산 결과 공유
- 큰 글씨와 넓은 입력 영역을 적용한 반응형 화면

## 계산 기준

두 선택 모두 기존 예금 만기일을 기준으로 비교합니다.

```text
기존 예금 유지
= 기존 예금 만기 세후 이자

새 예금으로 갈아타기
= 기존 예금 중도해지 세후 이자
 + 기존 만기일까지의 새 예금 세후 이자
 - 갈아타기 비용
```

모든 이자는 단리·연 365일 기준입니다. 새 예금은 기존 원금만 기존 예금
만기일까지 운용하는 것으로 계산합니다.

## 실행

```bash
npm install
npm start
```

테스트와 프로덕션 빌드:

```bash

npm run build
```
